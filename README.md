# نقاشباشی (Naghash Bashi) 🎨
## بازی آنلاین چندنفره حدس نقاشی (مشابه Doodle Kong / Skribbl.io) به زبان فارسی

یک بازی پارتی آنلاین و ریل‌تایم، جذاب و رقابتی طراحی‌شده بر بستر WebRTC (PeerJS)، HTML5 Canvas و معماری Progressive Web App (PWA).

---

### 🌟 ویژگی‌های کلیدی (Key Features)

1. **شبکه‌سازی بلادرنگ P2P بدون نیاز به سرور (Serverless GitHub Pages Ready):**
   - اتصال مستقیم همتا به همتا (P2P Mesh / Host Architecture) با استفاده از WebRTC (PeerJS CDN).
   - ساخت اتاق با کد اختصاصی ۶ حرفی (مانند `NB-256`) یا لینک مستقیم اشتراک‌گذاری (`index.html?room=NB-256`).
   - قابل اجرا و انتشار ۱۰۰٪ رایگان و مستقیم روی **GitHub Pages** بدون نیاز به سرور اختصاصی، هاست ابری یا کانفیگ پیچیده.
   - همراه با سرور توسعه محلی سریع (`node server.js`) با استاندارد Zero-Dependency در Node.js.

2. **سیستم لابی و مدیریت اتاق‌ها (۲ تا ۶ بازیکن):**
   - تعیین نام بازیکن به همراه پالایش هوشمند ۳ لایه عبارات و نام‌های نامناسب (فارسی، انگلیسی، فینگلیش و دورزدن‌های علائم).
   - انتخاب آواتار از میان کاراکترهای شاداب و متنوع (🎨، 🦁، 🐱، 🚀، ☕، 🤖، 🦊، 👑).
   - سقف سخت‌گیرانه ظرفیت اتاق: دقیقاً بین ۲ تا ۶ بازیکن در هر اتاق.
   - نمایش لیست زنده بازیکنان، وضعیت آمادگی، تاج میزبان، و پنل کنترل میزبان جهت انتخاب تعداد دورها (۲، ۳، ۵ دور).
   - امکان افزودن **بازیکنان ربات (AI Bots)** جهت تمرین انفرادی یا پر کردن جای خالی دوستان با یک کلیک!

3. **حلقه گیم‌پلی نوبتی (Drawing & Guessing Loop):**
   - **انتخاب کلمه:** در آغاز نوبت، ۳ کلمه در سطوح سختی متفاوت (آسان، متوسط، سخت) همراه با شمارشگر معکوس ۱۵ ثانیه‌ای به نقاش پیشنهاد می‌شود.
   - **بوم نقاشی تعاملی و روان:** بوم واکنش‌گرا با رزولوشن داخلی پایدار، سیستم مختصات نسبی (سازگار با انواع نمایشگر دسکتاپ، تبلت و موبایل)، پالت ۱۲ رنگی شاداب، ضخامت‌های ۴ گانه قلم، ابزار پاک‌کن، ابزار سطل رنگ (Flood Fill هوشمند) و بازگشت به عقب (Undo).
   - **حدس کلمه و خط‌چین‌ها:** سایر بازیکنان خط‌چین‌های حروف کلمه (`_ _ _ _`) و دسته‌بندی موضوعی را به همراه باز شدن تدریجی حروف کمکی (Hint) در ثانیه‌های ۳۸ و ۱۸ مشاهده می‌کنند.
   - **چت بلادرنگ و ارزیابی حدس:**
     * ارزیابی دقیق متن با نرمال‌ساز پیشرفته فارسی (یکسان‌سازی ک/ك، ی/ي، نیم‌فاصله، ه/ة، اعراب، تنوین، کشیدگی کلمات و حذف علائم).
     * تشخیص حدس‌های بسیار نزدیک (`نزدیک بود!`) با الگوریتم فاصله‌ی لون‌اشتاین (Levenshtein Distance).
     * مخفی‌سازی پاسخ صحیح از چت عمومی پس از حدس موفق و نمایش پیام شادی اختصاصی: `🎉 [نام بازیکن] کلمه را حدس زد!`.
     * امتیازدهی تصاعدی: سرعت بیشتر در حدس = امتیاز بالاتر (تا ۵۰۰ امتیاز). نقاش نیز به ازای حدس صحیح سایرین امتیاز تشویقی دریافت می‌کند.
   - **پایان نوبت و سکوی قهرمانی:** نمایش کلمه صحیح و امتیازات هر دور، و در نهایت سکوی سه‌بعدی مدال‌آوران (🥇 طلا، 🥈 نقره، 🥉 برنز) با انفجار کاغذ رنگی (Confetti) و موزیک پیروزی.

4. **بانک جامع کلمات فارسی (Over 210+ Curated Persian Words):**
   - اشیا، ابزار و تکنولوژی (ساعت، دوچرخه، جاروبرقی، میکروسکوپ، لپ‌تاپ، تبلت و...)
   - خوراکی‌ها و نوشیدنی‌های اصیل (قورمه‌سبزی، کباب کوبیده، نان بربری، فالوده، پیتزا و...)
   - حیوانات و طبیعت (زرافه، اسب آبی، طاووس، خرس پاندا، رنگین‌کمان و...)
   - مشاغل و شخصیت‌ها (برنامه‌نویس، فضانورد، دندان‌پزشک، آتش‌نشان، نینجا و...)
   - افعال، حالات و ضرب‌المثل‌ها (سنگ مفت گنجشک مفت، قطره قطره جمع گردد، فیل هوا کردن و...)

5. **تجربه کاربری لمسی و PWA موبایل:**
   - پشتیبانی از `manifest.json` و `sw.js` برای نصب به عنوان برنامه مستقل (Standalone PWA) روی اندروید و iOS.
   - اعمال `touch-action: none` و مدیریت رویدادهای `PointerEvents` جهت جلوگیری از هرگونه اسکرول یا زوم ناخواسته هنگام نقاشی با انگشت.

6. **طراحی صدا با Web Audio API خالص:**
   - افکت‌های صوتی بدون نیاز به دانلود فایل‌های صوتی حجیم: خش‌خش مداد، زنگوله موفقیت حدس، تیک‌تاک ساعت، بوق ثانیه‌های پایانی و مارش پیروزی.

### 🚀 نحوه اجرا و انتشار (Run & Deploy)

#### الف) انتشار روی گیت‌هاب پیجز (GitHub Pages):
1. کل مخزن را به ریپازیتوری گیت‌هاب خود Push کنید.
2. در تنظیمات مخزن به بخش **Settings > Pages** بروید.
3. شاخه `main` یا `master` و شاخه ریشه `/ (root)` را انتخاب کرده و Save را بزنید.
4. بازی در آدرس `https://<username>.github.io/<repo-name>/` بدون نیاز به هیچ سروری آماده بازی آنلاین با دوستان در سراسر دنیا خواهد بود!

#### ب) اجرای محلی با سرور استاتیک Node.js:
```bash
node server.js
```
سپس مرورگر خود را باز کرده و به آدرس زیر بروید:
```
http://localhost:3000
```

### 🧪 اجرای آزمون‌های خودکار (Automated Tests)

برای بررسی صحت تمامی ماژول‌ها دستورات زیر را اجرا نمایید:
```bash
node test/test_words.js                    # آزمون بانک کلمات و نرمال‌ساز اولیه
node test/test_normalizer_deep.js           # آزمون عمیق کیبوردهای فارسی و خطاهای تایپی
node test/test_room_logic.js               # آزمون ماشین وضعیت اتاق، ظرفیت ۶ نفر و امتیازدهی
node test/test_multiplayer_simulation.js    # شبیه‌سازی کامل مسابقه ۶ نفره در چند دور
node test/test_network_and_drawer.js       # آزمون نوبت نقاش مهمان، تحویل محرمانه کلمه و ضداسپویلر چت
node test/test_canvas_history_and_undo.js  # آزمون ثبت تاریخچه بوم، بازیابی پس از تغییر اندازه و Undo
node test/test_bot_lifecycle.js            # آزمون مدیریت چرخه حیات و لغو بدون نشت بات‌ها
node test/test_websocket_relay.js          # آزمون رله وب‌سوکت محلی بدون وابستگی (RFC 6455)
node test/test_profanity.js                # پالایش ۳ لایه نام‌های نامناسب
node test/test_pwa.js                      # اعتبارسنجی مانیفست و سرویس‌ورکر PWA
node test/test_server.js                   # اعتبارسنجی تمام اندپوینت‌های سرور استاتیک و وب‌سوکت
```
